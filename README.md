# Battery Formation System
### Quality Asian Battery — Formation Department

A web app for battery formation reading collection, hosted on GitHub Pages with Google Sheets integration.

---

## 🚀 How to Deploy on GitHub Pages (5 minutes)

### Step 1 — Upload files to GitHub
1. Go to [github.com](https://github.com) and log in as `qualityasianbattery-byte`
2. Click **New repository** (green button)
3. Name it: `battery-formation`
4. Set to **Public**
5. Click **Create repository**
6. Click **uploading an existing file**
7. Drag and drop all 4 files:
   - `index.html`
   - `style.css`
   - `app.js`
   - `README.md`
8. Click **Commit changes**

### Step 2 — Enable GitHub Pages
1. In your repository, click **Settings**
2. Left menu → **Pages**
3. Under "Source" → select **Deploy from a branch**
4. Branch: **main** → folder: **/ (root)**
5. Click **Save**

### Step 3 — Your app is live!
Wait 1-2 minutes, then open:
```
https://qualityasianbattery-byte.github.io/battery-formation
```

Share this link with your whole team — everyone gets the latest version automatically!
